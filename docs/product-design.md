# 产品设计说明：墨西哥电视直播

本文说明产品的定位、用户流程、页面结构和视觉规范。它与 `AGENTS.md` 中的需求互为补充：需求说明“做什么”，本文说明“怎么呈现”。

可直接打开的设计原型：[design-demo.html](design-demo.html)（双击即可，无需服务器）。

## 1. 定位

- 一句话：在一个页面里，找到并观看墨西哥主流电视台的直播，并了解每个频道的背景。
- 核心价值：
  1. 频道多，但一眼就能看出哪个能直接看、哪个要去 YouTube、哪个仅限墨西哥。
  2. 每个频道都有中文简介，帮助不熟悉西班牙语节目的用户选台。
  3. 播放器体验接近主流流媒体平台。

## 2. 用户与场景

| 用户 | 场景 | 关注点 |
| --- | --- | --- |
| 在墨西哥或拉美有兴趣的中文用户 | 想看新闻或综艺，偶尔看看当地节目 | 快速开播、知道频道在讲什么 |
| 学西班牙语的用户 | 通过新闻或综艺练听力 | 频道分类、清晰的画质、可调字幕（未来） |
| 分享链接的用户 | 把某个频道发给朋友 | 链接可直接打开对应频道 |

## 3. 信息架构

```
页面
├─ 顶栏：品牌 · 搜索 · 墨西哥城/北京时间
├─ 主区（左）
│  ├─ 播放器（吸顶于手机端）
│  │  ├─ 视频画面与 Video.js 控件
│  │  ├─ 覆盖层：加载中 / 地区限制 / 暂不可用 / YouTube 未直播
│  │  └─ 右键菜单与统计面板
│  └─ 频道信息卡：标签 · 操作（收藏、剧场、分享、官网）· 简介 · 信号源
└─ 侧栏：频道列表
   ├─ 分类 chips（全部 · 综合娱乐 · 新闻资讯 · 公共文化 · 我的收藏）
   ├─ 频道项（台标 · 名称 · 中文名 · 状态 · 收藏）
   └─ 图例（可播放 · YouTube · 仅限墨西哥 · 官方平台）
```

## 4. 关键流程

### 4.1 打开页面
1. 读取哈希 `#/id`，没有则恢复上次频道，否则默认 Imagen Televisión。
2. 并行检测 HLS 信号和 YouTube 可达性（最多等待 4 秒）。
3. 选择最佳信号源并开始播放。播放器静音自动播放失败时，显示“点击开启声音”。

### 4.2 信号不可用
1. HLS 失败后，自动尝试同一频道的下一个信号源，并用 toast 告知。
2. 所有信号都失败，显示对应原因的覆盖层：地区限制、暂不可用，并提供“重新连接”“官网”“下一个频道”。

### 4.3 地区限制
- 覆盖层直接说明“这路信号仅限墨西哥境内播放”，不使用“错误”之类的措辞，避免让用户以为是自己操作有误。

### 4.4 YouTube 不可达
- 覆盖层说明“当前网络无法访问 YouTube”，并提供“仍然尝试”和“下一个频道”。

### 4.5 分享
- 手机：调用系统分享面板。
- 桌面：复制当前地址，toast 提示。

## 5. 视觉规范

- 风格：深色、低干扰，播放器是视觉中心。
- 色彩：
  - 背景：近黑色（`#07080b` 一带），顶部有极淡的光晕。
  - 主色：青绿（用于播放按钮、选中态、可播放状态）。
  - 状态色：可播放为绿色，YouTube 为红色，仅限墨西哥为琥珀色，官方平台为蓝色。
- 台标：没有官方图片时，使用渐变色的字母块（如 `3`、`N+`、`AI`），避免使用未授权的商标图片。
- 字体：系统无衬线字体，中文优先使用 PingFang SC / 微软雅黑。
- 圆角：卡片 14–20px，按钮和标签使用胶囊形。
- 动效：覆盖层淡入，按钮悬停轻微变亮。尊重 `prefers-reduced-motion`。

## 6. 响应式

| 宽度 | 布局 |
| --- | --- |
| ≥ 1240px | 播放区 + 右侧频道列表 |
| 720–1240px | 列表收窄 |
| < 720px | 播放器吸顶，频道信息和列表在下方，列表项留出边距 |

剧场模式：播放区加宽，侧栏收起。

## 7. 可访问性

- 所有图标按钮都有 `aria-label` 或 `title`。
- 频道列表支持键盘：上下方向键移动，回车或空格选择。
- 覆盖层的按钮可以用 Tab 访问。
- 播放器控件由 Video.js 提供，已具备基础的键盘和屏幕阅读器支持。

## 8. 版权与合规

- 页面首屏和页脚都写明：不存储、不转码、不转发音视频，节目版权归电视台所有。
- 每个频道的信号来自电视台公开的官方源或其官方 YouTube 频道。
- 无可嵌入信号的频道，只提供官网链接，不做任何绕过地区限制的处理。
